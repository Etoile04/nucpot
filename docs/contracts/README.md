本目录存放 nucpot 项目相关的合同规格书、外部技术规范、招投标文档等**正式契约性文件**的 Markdown 整理版。

## 命名规范

- 文件名格式:`<合同编号>-<文档类型>.md`
- 合同编号使用原始文档中的官方编号
- 文档类型常用值:`specification`(技术规格书)/`contract`(合同正文)/`sow`(工作说明书)/`tender`(招投标书)

## 整理原则

1. **保留原文完整性**:所有合同条款、表格、量化指标必须 100% 保留
2. **结构化**:去除原文档的页眉/页脚/分页符噪声,使用 Markdown 章节和表格重新组织
3. **可追溯**:每个条款保留原章节号(§3.1.2 等),便于在 PR/Issue 中引用
4. **附录增强**:规格书类文档增加"关键约束一览"和"与本项目路线图对应关系"两个附录,便于工程团队快速检索

## 引用规范

在 nucpot 项目文档、PR 描述、Issue 描述中引用本目录文件时,使用相对路径:

```markdown
依据 [FMDB-410400-GG1 §5.5](../contracts/FMDB-410400-GG1-specification.md#55-知识图谱查询与应用能力)
知识图谱实体抽取准确率应不低于 85%。
```

## 保密要求

本目录文件属于**非密**类合同文档,仅可在 NFMD 项目内部使用,不得对外公开传播(详见 [FMDB-410400-GG1 §11](./FMDB-410400-GG1-specification.md#11-成果产权知识产权归属和分享))。
