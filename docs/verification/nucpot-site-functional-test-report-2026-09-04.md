## 1. 结论摘要

平台已完成设计文档 **P0 的核心链路**(浏览、检索、详情、下载、文献管理),部分超出 P0(本体知识图谱、语义 RAG 检索、博客文档),整体可用。但存在 **1 个生产调试信息泄漏、2 个影响主流程的功能缺陷(元素筛选失效、列表接口间歇失败)**,以及 API 性能远超设计指标的问题。P1(Benchmark 中心)与 P2(投稿/审核/DOI)功能基本未落地,详情页缺少设计要求的文献关联区、适用性声明、温压范围等关键元数据。

## 4. 问题清单

### P0(高危,建议立即修复)

**问题 1|生产环境调试信息泄漏**
- 页面:/ontology(iframe 内)
- 现象:页面直接渲染调试文本:`=== NFM-3478 DEBUG === hook source: scan #10 (no cy yet) cy captures: 0 cy: NOT FOUND canvases in DOM: 2 cytoscape-registered canvases: 0 elements with _cyreg attr: 0`
- 同时表明 Cytoscape 交互图初始化失败(`cy: NOT FOUND`、`cytoscape-registered canvases: 0`),当前可能仅静态图可用。
- 证据:t11_ontology_debug.png
- 建议:移除/门控调试输出;修复 Cytoscape 挂载;此问题带工单号(NFM-3478),说明是遗留调试代码未清理。

### P1(严重,影响核心功能)

**问题 2|元素筛选完全失效**
- 页面:/browse 与 /search 的"元素筛选"侧栏
- 现象:元素选择区恒显示"无匹配元素";在搜索框输入 "U"(应匹配 U、UO2 等大量元素)仍无结果。
- 影响:设计文档 P0 要求"按元素检索"是核心检索维度,当前不可用。
- 证据:t02_browse_viewport.png(加载完成后的"无匹配元素"状态)
- 可能原因:元素聚合接口失败或前端渲染条件错误(左侧列表本身都未渲染出任何元素标签)。

**问题 3|列表接口间歇性失败 "加载失败:Failed to fetch"**
- 页面:/browse(勾选筛选后多次复现)、重载后偶发
- 现象:结果区显示"暂无数据 + 加载失败:Failed to fetch";重试可恢复。
- 关联实测:后端 `/api/v1/potentials?page=1&page_size=12` 8 次采样延迟 **1.27s~5.55s**(详见附录 B),远超前端可承受范围;怀疑前端 fetch 有超时中断,慢请求被 abort 后报 Failed to fetch。
- 证据:t03b_browse_filter_eam_loaded.png、t04_browse_eam_state.png
- 建议:①后端列表查询优化(索引/缓存,目标 <500ms);②前端失败时提供重试按钮;③排查超时阈值。

### P2(中危)

**问题 4|API 性能远超设计指标**
- 设计要求:常规搜索响应 < 500ms;实测列表 API 1.27~5.55s(超 3~10 倍),且抖动大。
- 影响:直接导致问题 3,并拖慢全部列表页首屏。

**问题 5|语义(RAG)检索匿名用户报"登录已过期"**
- 现象:匿名状态提交语义查询,返回"登录已过期,请重新登录后再试"+ 前往登录链接。
- 问题:①用户从未登录过,文案应为"该功能需登录"而非"登录已过期";②UI 入口未标注需登录;③设计文档将检索列为 P0 公开功能。
- 证据:DOM 记录(语义查询结果区)。

**问题 6|反馈表单空提交无任何响应**
- 现象:标题/详情均为空时点击"提交反馈",无校验提示、无成功/失败反馈,页面无变化。
- 证据:t14_feedback_empty_submit.png
- 建议:必填校验 + 提交状态反馈(loading/成功/失败)。

**问题 7|材料物性页全面无数据**
- 现象:抽查 UO2、PuO2 等材料的 /properties 页均为"暂无属性数据";而 `/api/v1/properties` 有数据(挂在 dataset 维度)。材料与属性数据的关联缺失。
- 影响:设计文档目标用户 3(实验-模拟协同团队)的核心场景无法使用。

**问题 8|详情页元数据缺失(对照设计)**
- "验证状态"字段为空值(t06_detail_overview.png);"版本"为"-";"DOI"为 "-"。
- 缺失字段:温压范围、成分范围、适用相、预期用途、已知局限、质量等级、许可协议、贡献者、发布日期(设计§详情页线框全部要求)。

### P3(低危/体验)

**问题 9|材料详情时间戳原始格式展示**:直接显示 `2026-09-01T01:29:54.036093Z`,应本地化格式化。
**问题 10|"重置筛选"未清空元素搜索输入**(/browse:重置后输入框仍残留 "U")。
**问题 11|API page_size 被静默截断**:请求 page_size=50 实际返回 20 条,无提示(影响调用方分页逻辑)。
**问题 12|嵌套交互元素**:`查看知识图谱` 为 `<a>` 包裹 `<button>`(HTML 规范违规,影响无障碍)。
**问题 13|材料名称质量**:列表中大量原始英文标识符(如 `alpha_U_solid_solution`、`Test sc`),"Test sc" 疑似测试数据混入生产;化学式列大面积 "—"。

## 6. 测试说明与局限性

### 6.1 测试范围
- 全部页面按匿名用户视角测试;未注册账号、未提交任何写操作(除一次反馈空提交——被服务端/前端拦截,无数据写入)。
- API 探测仅做只读 GET。

### 6.2 数据核验亮点
- 下载文件 SHA256 实测比对:`6170422480edd9337507654a85350f63114eb19b4fa3dc33580b50f38f72c827` 与页面展示一致(完整性可信)。

### 6.3 测试环境事故记录(影响结论可信度)
测试使用的内置浏览器会话中,输入分发(点击)与截图管线多次间歇性失效并恢复。受此影响:
- "语义 RAG 切换"在输入失效期表现为不可切换,**输入恢复后复测确认功能正常**——已从问题清单排除;
- 对比勾选流程恰逢失效窗口,多次重试未完成,如实标注"环境受阻",**不能据此判定对比功能有缺陷**;
- 曾出现一次列表区空白无提示的快照,经查为测试浏览器渲染器崩溃(快照长度为 0),未计入站点问题。

## 7. 改进建议(按优先级)

### 立即(本周)
1. **移除 /ontology 的 NFM-3478 调试输出**,修复 Cytoscape 初始化(问题 1)。
2. **修复元素筛选**(问题 2):排查元素聚合接口/前端渲染,这是核材料用户("找 U-Mo 的势")的第一检索路径。
3. **后端列表查询提速**(问题 3/4):`/api/v1/potentials` 加缓存(Redis,设计文档已规划)+ 检查 N+1 查询;前端对 Failed to fetch 提供自动重试与手动重试按钮。

### 短期(2~4 周)
4. 详情页补齐设计要求的元数据:温压范围、适用相、成分范围、质量等级、许可协议、适用性声明(推荐/谨慎/不建议),并接入文献关联(文献库已有 17 篇数据可关联)。
5. 语义检索入口标注"需登录",文案改为"该功能需要登录后使用";或在匿名时直接引导注册。
6. 反馈表单增加必填校验与提交反馈;清理 `Test sc` 等测试数据;时间戳格式化。
7. 首页补上设计要求的统计区/热门势函数/体系导航(现有数据即可支撑)。
8. 文件下载改为后端签名临时链接(设计§技术架构),保留公开桶作冷备。

### 中期(1~2 月)
9. 落地 Benchmark 中心(设计 P1):先以静态"验证属性"扩展为结构化 benchmark_results 表(设计§第四部分 schema 已定义),再做自动化流水线。
10. 打通材料 ↔ 物性数据关联(问题 7),让"实验-模拟对照"场景可用。
11. 增加辐照场景标签筛选维度(核材料特有需求§4)。
12. 建立性能基线:列表 <500ms、首屏 <2s 的监控告警(设计§非功能需求)。
