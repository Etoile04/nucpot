## 3. 变更内容

### 3.1 开放实施(R1)
- `/api/v1/lightrag/query` 移除 `require_editor` → 匿名可用;端点级限流(slowapi per-route,默认 5/min/IP,env 可配)
- 前端:移除「需登录」墙与条件渲染;查询空结果 → 「知识库暂未覆盖该问题」+ 引用数随结果展示(9 refs 形态)
- sidecar 认证由 NFM-4481 独立票处理(9621 零认证)

### 3.2 对账与降级(R2)
- Celery beat 每日任务:文献库(completed)vs LightRAG documents diff → 重灌缺失(BUG-04 钩子静默失败的兜底)
- 超时回退:查询超时(30s)→ ILIKE 文本检索,响应携带 `fallback: true` → 前端徽标「语义检索超时,已回退文本检索」
- 前端 loading 对 fresh 查询提示真实预期(NFM-4525 修复前)

## 4. 验收标准

- [ ] 匿名 `/search` 语义模式可用且返回带引用结果(生产实测)
- [ ] 限流生效:超配额请求 429,UI 有友好提示
- [ ] 分层 SLA 监控:缓存命中 P95<1s;fresh P95<30s(NFM-4525 修复后重测收紧 <10s)
- [ ] 对账任务上线后连续 3 天零缺失(diff 报告留痕)
- [ ] 超时回退路径实测:标注可见,回退结果可用
- [ ] 空结果诚实文案 + 引用数展示上线

## 5. 边界与依赖

- **不在本 spec**:sidecar 认证(NFM-4481)、NFM-4525 thinking-mode 修复(backlog,修后触发 SLA 收紧)、G1 线(另 spec)
- **衔接**:数据版本(#1280)成熟后,索引源切换发布版数据集
